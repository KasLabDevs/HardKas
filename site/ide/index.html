01 · SilverScript

Editor, compiler and covenant inspection

Edit .sil contracts directly in your real project folder with SilverScript syntax highlighting, completions and instant compilation with Ctrl+Enter.

  • Compile with the pinned silverc toolchain and see diagnostics inline in the editor.
  • Inspect compiled contract artifacts, entry points, dispatch tags and P2SH script details.
  • Every action executes the underlying hardkas CLI and saves standard .hardkas/ records.

02 · Local Simnet

Real rusty-kaspad node in Docker, plus synthetic simulator

Switch between the instant in-memory simulator, a private rusty-kaspad simnet node managed in Docker, and public testnet-10 from the environment bar.

05 · Getting Started

Install HardKAS IDE and open your first project

Every HardKAS IDE project is a standard folder on disk with hardkas.config.ts and .hardkas/, so you can switch seamlessly between the visual workbench and your terminal.

1. Requirements

Node.js 24.22.1 with npm (the IDE drives the hardkas CLI). Docker Desktop is only required for the local rusty-kaspad node; the simulator needs no Docker.

2. Install & Open

Download the installer for Windows, macOS or Linux from GitHub Releases, then create a new project or open an existing HardKAS workspace.

3. Docs & Source

Follow the IDE installation guide, browse the full IDE reference, or inspect the HardKasIDE repository.

Execution worlds & policy: Mainnet signing and broadcast are disabled by HardKAS policy. Use the IDE across the in-memory simulator, local Docker simnet and public testnet-10.
Installer note: The Windows installer is not code-signed yet, so Windows SmartScreen may ask you to confirm before running.
