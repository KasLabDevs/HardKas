# `hardkas console`

## `hardkas console`

### Synopsis (Generated)

**Purpose:** Open an interactive REPL with an in-memory simulator harness (h) and hash/format helpers; no network is contacted stable

#### Options

- `--network &lt;name&gt;` (Default: `simnet`): Network label for the simulated state (nothing connects to it)
- `--accounts &lt;n&gt;` (Default: `3`): Number of simulated accounts
- `--balance &lt;sompi&gt;` (Default: `100000000000`): Initial balance per account in sompi
