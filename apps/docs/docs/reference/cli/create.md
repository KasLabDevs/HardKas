# `hardkas create`

## `hardkas create`

### Synopsis (Generated)

**Purpose:** Scaffold a new HardKAS project from a template stable

#### Arguments

- `&lt;template&gt;` (Required): Name of the template (e.g. payment-app, batch-payments)
- `&lt;dest&gt;` (Required): Destination directory

#### Options

- `--install` (Default: `false`): Run npm install automatically after scaffolding
- `--json` (Default: `false`): Output results as JSON
