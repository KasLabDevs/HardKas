### Synopsis (Generated)

**Purpose:** Install a pinned toolchain, verifying the release asset and every file against the pin

#### Arguments

- `&lt;id&gt;` (Required): 

#### Options

- `--from-file &lt;asset&gt;`: Use a release asset already on disk instead of downloading it
