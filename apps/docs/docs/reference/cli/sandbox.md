# `hardkas sandbox`

## `hardkas sandbox`

### Synopsis (Generated)

**Purpose:** Start a temporary, ephemeral HardKAS local experimentation environment

#### Options

- `--with-node`: Start a simulated Kaspa node in the background with mining
- `--recipe &lt;name&gt;`: Run an initial recipe/template inside the sandbox
- `-p, --port &lt;port&gt;` (Default: `3000`): Port for dashboard
- `-h, --host &lt;host&gt;` (Default: `localhost`): Host for dashboard
