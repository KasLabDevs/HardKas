# `hardkas local`

## `hardkas local wizard`

### Synopsis (Generated)

**Purpose:** Guided Igra L2 (EVM) check, an L2 lab: JSON-RPC, EVM account and its balance; not a Kaspa L1 setup experimental

#### Options

- `--profile &lt;name&gt;` (Default: `igra`): L2 network profile name
- `--account &lt;name&gt;` (Default: `dev_alice`): EVM account name in hardkas.config (if it is missing, a key is printed for you to add)
- `--non-interactive` (Default: `false`): Skip interactive prompts (will fail if input required)
- `--json` (Default: `false`): Output as JSON
