# `hardkas repair`

## `hardkas repair`

### Synopsis (Generated)

**Purpose:** Report an outdated workspace, lock files in .hardkas/, torn JSONL tails and a corrupt query store; --force repairs them beta

#### Options

- `--json` (Default: `false`): Output results as stable JSON schema
- `--force` (Default: `false`): Apply the repairs (without it, repair only reports). Removes lock files without checking whether their process is alive
