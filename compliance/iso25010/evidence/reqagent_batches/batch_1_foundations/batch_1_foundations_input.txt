Requirement HK-REQ-001 states that the system must strictly block all mainnet network connections, mainnet private key signing, and mainnet transaction broadcasting before opening any socket or unlocking any key.
Requirement HK-REQ-002 states that the system shall resolve the ExecutionTarget tuple (mode, domain, network) first and validate account, artifact, and receipt compatibility before executing any operation.
Requirement HK-REQ-003 states that the security module must strip ANSI escape sequences and redact all 64-hex private keys, extended keys, mnemonics, secret fields, and URL credentials before logging or persisting artifacts.
Requirement HK-REQ-004 states that the lock manager must acquire workspace file locks in a strict hierarchical rank order using AsyncLocalStorage reentrancy, recover stale dead-PID locks after 30 seconds, and omit CLI arguments from lockfiles.
Requirement HK-REQ-005 states that all durable state writes must write to a unique temporary sibling file, flush to disk with fsyncSync, and atomically rename with up to 5 backoff retries on Windows EPERM or EBUSY errors.
Requirement HK-REQ-006 states that the toolchain manager must verify exact SHA-256 digests and byte sizes for external kaspa-wasm v2.1.0 and silverc v1.0.0 binaries and pin Docker images rusty-kaspad v2.1.0 and cpuminer by immutable SHA-256 digest.
Requirement HK-REQ-007 states that external binary execution for the SilverScript compiler must use child_process.execFile without shell interpolation to prevent command injection.
Requirement HK-REQ-008 states that the system shall convert between KAS decimal strings and bigint Sompi units (100,000,000 sompi per KAS) without floating-point precision loss and validate network-specific Bech32 address prefixes.
Requirement HK-REQ-009 states that the configuration loader shall load TypeScript and JavaScript hardkas.config files via jiti and resolve network endpoints, execution targets, and fee policies deterministically.
Requirement HK-REQ-010 states that the observability package shall provide structured logging, metric counters, Prometheus text export formatting, and distributed trace spans with zero external runtime dependencies.
Requirement HK-REQ-011 states that the monorepo package dependency graph must strictly obey the five-tier hierarchy from Level 0 Foundations through Level 4 Presentation without upward circular dependencies.
Requirement HK-REQ-012 states that the toolchain manager should support pinned silverc v1.0.0 compiler binaries on macOS (darwin-arm64 and darwin-x64) in addition to Windows and Linux, and provide a signed binary for the SilverScript VM runner.
